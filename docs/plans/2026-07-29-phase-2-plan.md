# Phase 2 — PLAN (Ottomate design-system rebuild) · authored 2026-07-29

**The intelligence layer — what turns "competent" into "excellent" (spec §5 Phase 2, Pillars D + E).**
The dictionaries the design AI loads on activation, plus the real onboarding intake. Governed by §7
(build → verify with evidence → record → plan next). Most of this is autonomous: the spec + open sources
supply the material. The **one** external-research dependency is the Mobbin MCP (flagged, owner to do).

## WS
- **P2.1 — Motion dictionary (20 patterns).** The spec's 20-pattern table as machine-readable data: each
  tagged productive/expressive, semantic motion tokens, good-with/avoid, reduced-motion swap. Feeds the
  generator (the owner's taste is expressive → reach for these). *Autonomous.*
- **P2.2 — Chart-by-data dictionary.** The FT Visual Vocabulary (open-source, CC-BY): 9 data-relationships →
  recommended chart types, each with an encoding-accuracy rank (Cleveland–McGill) + Datawrapper-style "avoid"
  notes. So a data panel picks the RIGHT chart for the relationship, not a default. *Autonomous.*
- **P2.3 — Pattern/combination dictionary + combination_rules.** The graph `app_archetypes → layout_templates
  → section_patterns → component_refs (→ master_components)`, plus **combination_rules** ("good together /
  avoid together" as first-class facts). *Autonomous; combination_rules brainstormed inline.*
- **P2.4 — Onboarding intake (~30 Qs, 5 stages, real pre-fill).** Expand from ~4 questions to the staged ~30
  (research / structure / style / interaction / silent-constraints), each enum+default, **pre-filled by
  reading the repo/DB**, persisted per project, re-run only on what's rebuilt. *Autonomous.*
- **Mobbin MCP — RESEARCH (owner, external).** Licensing + auth + rate limits before wiring the live
  section/flow reference. Everything else ships without it.

## Design decisions taken to keep moving (owner can redirect)
- Dictionaries are **data files + a small loader/query API** in the plugin (`data/dictionaries/*.json` +
  `scripts/generation/dictionaries.mjs`), unit-tested — same shape as the rest of the method, not an app UI.
- Chart source = **FT Visual Vocabulary** (CC-BY, attributed) — no licensing blocker.
- The intake extends the existing `data/design-questions.json` + the context gate, not a greenfield table.

## Verify (each WS)
Run the loader/query with real inputs and show output; a must-fail where a rule can reject (e.g. an unknown
relationship, a reduced-motion swap that is missing); tests with must-pass + must-fail.

## Exit (§7)
Verify each WS with evidence · record a Phase 2 completion note · plan Phase 3 (catalog + graduation).
